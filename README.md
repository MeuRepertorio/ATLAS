# ATLAS — Quatro Áreas do Conhecimento

Biblioteca interativa, pública e responsiva sobre **Ética, Legislação, Logística e Desenvolvimento de Modelo de Negócio (DMN)**. Criada como material de estudo para 26 de outubro de 2026.

## Conteúdo
- 27 capítulos extensos, baseados nos materiais de aula existentes.
- 62 perguntas explicadas, 20 perguntas de múltipla escolha de referência e estudos de caso adicionais.
- Quatro áreas independentes e relações entre as disciplinas.
- Pesquisa global, seleção por área, índice de capítulos, exemplos e sínteses de leitura.
- Glossário, fontes oficiais acessíveis e referências de material didático.
- Marcações de leitura gravadas **apenas no navegador** (`localStorage`), sem conta e sem banco de dados.
- Design responsivo, animações suaves, alternância claro/escuro e suporte à preferência de movimento reduzido.

## Publicar com GitHub Pages
1. Criar repositório **público** (por exemplo `Atlas-Quatro-Materias`).
2. Colocar **o conteúdo** desta pasta na raiz do repositório (não carregar apenas o ZIP).
3. Abrir **Settings > Pages > Deploy from a branch > main > /(root)** e salvar.
4. Esperar GitHub Pages mostrar **Visit site**. O endereço padrão deverá ter o formato `https://MeuRepertorio.github.io/Atlas-Quatro-Materias/` conforme o nome exato escolhido.
